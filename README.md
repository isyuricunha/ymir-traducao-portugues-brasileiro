## 📥 Como baixar a tradução

1. **Abra seu navegador** (Chrome, Firefox, Edge, etc.)
2. **Clique ou digite este link na barra de endereço:**

   ```
   https://github.com/isyuricunha/ymir-traducao-portugues-brasileiro/releases/latest
   ```

3. **Role a página para baixo** até ver a seção "Assets" (ou "Arquivos" em português)
4. **Você verá dois arquivos para download:**
   - `portuguese.zip` (formato normal)
   - `portuguese.7z` (formato compactado, precisa do 7-Zip)

💡 **Dica:** Se você não sabe qual baixar, baixe o `portuguese.zip` (o primeiro).

## 🔍 Como instalar a tradução

### Passo 1: Baixe o arquivo

- Clique no arquivo `portuguese.zip` (ou `portuguese.7z` se preferir)
- O download vai começar automaticamente
- **Espere o download terminar** (você verá a notificação no seu navegador)

### Passo 2: Extraia os arquivos

Você precisa **extrair** (descompactar) os arquivos que baixou:

#### Se você baixou o `portuguese.zip`

- **Clique com o botão direito** no arquivo `portuguese.zip`
- Selecione **"Extrair Tudo..."** (ou "Extrair aqui" se preferir)
- Escolha um local fácil de encontrar (como a **Área de Trabalho**)

#### Se você baixou o `portuguese.7z`

- Você precisa do programa **7-Zip** (gratuito)
- Baixe o 7-Zip em: [https://www.7-zip.org/](https://www.7-zip.org/)
- Instale o 7-Zip
- **Clique com o botão direito** no arquivo `portuguese.7z`
- Selecione **"7-Zip" > "Extrair aqui"**

💡 **Dica:** Depois de extrair, você verá uma pasta chamada `portuguese` com vários arquivos dentro.

---

### Passo 3: Encontre a pasta do jogo Ymir

A localização da pasta do jogo **depende de onde você comprou ou baixou o jogo**:

#### 🔹 Se você comprou na **Steam**

1. Abra a Steam
2. Clique em **"Biblioteca"** (no topo)
3. Encontre o jogo **Ymir** na lista
4. **Clique com o botão direito** no jogo
5. Selecione **"Gerenciar" > "Procurar arquivos locais"**
6. Isso vai abrir a pasta do jogo

#### 🔹 Se você comprou na **GOG**

1. Abra o GOG Galaxy
2. Clique em **"Biblioteca"**
3. Encontre o jogo **Ymir**
4. Clique nos **três pontinhos** (⋮) ao lado do jogo
5. Selecione **"Gerenciar instalação" > "Abrir pasta do jogo"**

#### 🔹 Se você comprou na **Epic Games**

1. Abra a Epic Games Store
2. Clique em **"Biblioteca"**
3. Encontre o jogo **Ymir**
4. Clique nos **três pontinhos** (⋮) ao lado do jogo
5. Selecione **"Gerenciar" > "Abrir pasta do jogo"**

#### 🔹 Se você tem o jogo **pirata/crackeado**

- Geralmente, a pasta do jogo fica em:

  ```
  C:\Jogos\Ymir
  ```

  ou

  ```
  C:\Program Files (x86)\Ymir
  ```

- Se não encontrar, procure no seu computador por uma pasta chamada **Ymir**

---

### Passo 4: Encontre a pasta "languages"

Dentro da pasta do jogo Ymir, você precisa encontrar a pasta **languages**:

1. Abra a pasta do jogo Ymir (como explicado acima)
2. Procure por uma pasta chamada **languages**
   - Se não encontrar, procure por **Ymir\languages**
   - Ou **Ymir\data\languages**

💡 **Dica:** Se você não encontrar a pasta `languages`, pode ser que ela não exista ainda. Neste caso, **crie uma pasta** com o nome `languages` dentro da pasta do jogo.

---

### Passo 5: Copie a tradução para a pasta do jogo

1. **Abra a pasta `portuguese`** que você extraiu (Passo 2)
2. **Selecione todos os arquivos** dentro dela (clique em um arquivo e aperte **Ctrl + A**)
3. **Copie os arquivos** (clique com o botão direito e selecione **"Copiar"** ou aperte **Ctrl + C**)
4. **Volte para a pasta `languages`** do jogo Ymir
5. **Cole os arquivos** (clique com o botão direito e selecione **"Colar"** ou aperte **Ctrl + V**)

---

### Passo 6: Substitua os arquivos (se necessário)

- Se já existir uma pasta `portuguese` na pasta `languages`, o Windows vai perguntar:

  ```
  Já existe uma pasta com este nome. Deseja substituir?
  ```

- **Clique em "Sim" ou "Substituir"** para todos os arquivos

💡 **Dica:** Se aparecer uma janela perguntando se você tem certeza, clique em **"Sim para todos"**.

---

### Passo 7: Selecione o idioma no jogo

1. Abra o jogo Ymir
2. Vá em **Configurações** ou **Options**
3. Procure por **Idioma** ou **Language**
4. Selecione **Português (Brasil)** ou **Portuguese (Brazil)**
5. **Reinicie o jogo** para as mudanças terem efeito

## ❓ Problemas comuns e soluções

### 🔴 "Não consigo encontrar a pasta languages"

- **Solução:** Crie uma pasta chamada `languages` dentro da pasta do jogo Ymir.

### 🔴 "O jogo não reconhece a tradução"

- **Solução 1:** Verifique se você copiou os arquivos para o local certo.
- **Solução 2:** Reinicie o jogo.
- **Solução 3:** Verifique se o nome da pasta está correto (`portuguese`).

### 🔴 "Aparece erro ao extrair o arquivo"

- **Solução 1:** Tente baixar o arquivo novamente.
- **Solução 2:** Use o `portuguese.zip` em vez do `portuguese.7z`.

### 🔴 "O jogo está em inglês ainda"

- **Solução 1:** Verifique se você selecionou o idioma correto nas configurações.
- **Solução 2:** Reinicie o jogo.
